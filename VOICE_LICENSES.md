## Excluded voices (not bundled)

- **piper en_GB-semaine-medium, en_US-hfc_female/male-medium, en_US-ryan-*, en_US-l2arctic-medium** — Training datasets licensed CC BY-NC / CC BY-NC-SA (non-commercial). Not commercial-safe.
- **piper en_US-lessac-*, and lessac-finetuned voices: en_GB-northern_english_male, en_GB-vctk, en_GB-aru, en_US-libritts_r, en_US-sam, en_US-arctic, en_US-reza_ibrahim, en_GB-alan-medium** — Base model trained on Lessac Blizzard-2013 data under a research licence (registration form; rights retained by Voice Factory/Lessac). Derivative status for commercial use is unclear, so excluded from the bundle even though some fine-tune datasets are permissive (e.g. VCTK CC BY 4.0 would add Irish/Scottish/Indian accents).
- **piper en_US-amy-*, en_US-danny-low, en_US-kusal-medium, en_GB-alan-low, en_GB-jenny_dioco-medium** — Model card says "License: See URL" with no clear permissive dataset licence (Mycroft mimic3 / Jenny dataset has custom terms). Not verified.
- **piper en_US-bryce-medium** — Public-domain data but fine-tuned from an unreleased base model of unknown provenance. Tested OK, excluded for caution.
- **piper en_US-john/kristin/kathleen/mike-medium, en_GB-cori-medium, en_US-ljspeech, en_US-hifi_tts_92** — Licence OK (PD/CC0/CC BY) and synthesis verified for most, but omitted to keep the ZIP small: Kokoro already covers these voice types. Can be added with tools/add_piper_voice.sh.
- **kokoro am_santa** — Synthesised unintelligible English in our QA (whisper word-overlap 0.08). Excluded on quality grounds.
- **kokoro other voices (af_alloy, af_aoede, af_jessica, af_kore, af_nicole, af_nova, af_river, af_sarah, am_adam, am_echo, am_eric, am_liam, non-English voices)** — Same Apache-2.0 licence; omitted for curation (lower upstream grades or redundant). Each is ~0.5 MB; add the .bin to voices/kokoro/voices/ to enable.
- **Coqui XTTS-v2 and other Coqui models** — Coqui Public Model License (CPML) is non-commercial; XTTS is also a voice-cloning model. Not used.
- **MeloTTS (MIT)** — Commercial-safe licence, but requires a PyTorch runtime (~2 GB of dependencies) and has no browser runtime; quality overlaps Kokoro. Not bundled.
- **Child voices** — No legitimately licensed, commercially usable child-speaker TTS voice was found among Piper/Kokoro. Youthful-sounding adult voices (bf_alice, bf_lily, af_sky) are provided instead; no cloning or pitch-faking of real children.

### Compliance notes

- **Recommended shipping path = pre-rendered MP3s + `dist/voice-engine.*.js`.** That contains only our MIT code and audio generated from Apache/MIT/CC-BY/CC0/public-domain voices. Generated audio is not a derivative of GPL tools.
- The optional **in-browser neural path** loads `vendor/kokoro/kokoro.web.js`, which bundles eSpeak NG (GPL-3.0) for phonemisation. Shipping that file in a closed-source commercial game needs a licence review (GPL obligations). For an educational web project that publishes its source, it is fine. It is never required: pre-rendered audio and the local server cover all features.
- CC BY 4.0 (Alba voice dataset, Kokoro is Apache): keep the credits text above in the game credits/about page.
- No voice is cloned from an identifiable person without consent. All datasets were recorded by consenting speakers/volunteers for open release.

Licence texts: `licenses/`.
